# Changelog

## 0.5.0

Initial release.

### Included in the initial release

- Loading Quantum Design MPMS 3 DC, VSM and AC exports, including mixed measurement families.
- Cataloguing and selecting runs, choosing moment channels, converting units and applying
  explicit specimen normalisations.
- Sweep selection, quality diagnostics and repeat aggregation with stated error conventions.
- Model fitting with iminuit, parameter uncertainties and comparisons across fitting ranges.
- Transition-candidate detection, smoothing-sensitivity assessment, response maps and fits
  through selected boundary points.
- Composable matplotlib figures, journal styles and export to multiple formats.
- A basic user guide, method conventions and an API reference.
- Git-derived build/runtime versions, with wheel and source-archive verification. Complete
  checkouts must be installed before import; built source archives remain usable without Git.
